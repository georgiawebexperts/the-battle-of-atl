# Original Krog street-art texture

2026-09-12 [codex-maclaptop]

Generated with the built-in image generation tool for The Battle of ATL. Original abstract layered spray-paint design, not a photograph or reproduction of a particular Krog mural. Source2172x724PNG retained without pixel edits. Intended as diffuse/base-color wall texture under game lighting. Horizontal tiling was requested but seam-free repetition is not yet verified.

Consumer: Scripts/create_krog_street_art.py imports the texture and builds a world-projected material for vertical tunnel surfaces; horizontal faces blend to concrete. Applied only in PiedmontKrogRoadReview. Current material has no authored normal map; lighting, repetition and face-dependent projection still require review.
