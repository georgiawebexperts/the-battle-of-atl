# Fictional taser prop

2026-09-13 [codex-maclaptop]

Project-authored yellow/black game prop; no third-party model download used.
Reproduce with `python3 Scripts/create_taser_model.py`, then run
`Scripts/import_taser_model.py` in Unreal's Python commandlet.

352 triangles; 24.5 × 5.2 × 19.7 cm. Three PBR material slots.
Forward is Unreal +X, up +Z. Muzzle marker is (17.5, 0, 4) cm.
The officer's hand joint is `Wrist_R`, not `Hand_R`.

Animation/finger-contact polish remains unfinished.
